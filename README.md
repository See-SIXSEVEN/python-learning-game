# 🐍 Python Quest: Codédex Edition (ระบบเรียนรู้และทดสอบภาษา Python ม.3)

เว็บแอปพลิเคชันระบบทดสอบและเรียนรู้การเขียนโปรแกรมภาษา Python เบื้องต้น สำหรับนักเรียนชั้นมัธยมศึกษาปีที่ 3 สไตล์เกม **Codédex (Retro Pixel-Art Dark Theme)** 🎮

ระบบได้รับการออกแบบโครงสร้างแบบ **แยกหน้าการทำงานชัดเจน (Multi-Page Architecture)** เพื่อประสบการณ์การใช้งานที่ราบรื่นและเป็นสัดส่วน:

---

## 🗺️ โครงสร้างหน้าเว็บแยกตามขั้นตอน (Page Flow)

```
[ หน้า 1: index.html ]  ──(กดปุ่มเริ่มภารกิจ)──>  [ หน้า 2: quest.html ]  ──(ทำครบหรือกดสรุป)──>  [ หน้า 3: summary.html ]
   หน้าลงทะเบียนนักเรียน                              หน้าทำแบบฝึกหัด Split Screen                      หน้าสรุปผล / อันดับ / พิมพ์ใบงาน
```

### 1. หน้าลงทะเบียน (index.html)
- หน้าจอเดี่ยวเฉพาะสำหรับกรอกข้อมูลนักเรียน:
  - ชื่อ - นามสกุล
  - ชั้นมัธยมศึกษา (ม.3/1 – ม.3/10)
  - เลขที่ (1 - 60)
  - เลือกอวาตาร์ประจำตัว (⚡, 🧙, 🤖, 🐱, 👾, 🎮)
- ปุ่ม **"🚀 เริ่มภารกิจพิชิตโค้ด (Start Quest)"** พร้อมเสียงเอฟเฟกต์เรโทร
- เมื่อกดส่งฟอร์ม จะบันทึกข้อมูลและนำทางไปยังหน้าทำแบบฝึกหัด (`quest.html`) ทันที
- มีระบบจำประวัติ หากเคยลงทะเบียนแล้วจะมีปุ่ม "▶ ไปหน้าทำแบบฝึกหัดต่อ" ให้กดเข้าสู่ด่านได้ทันที

### 2. หน้าเล่นเกมและทำแบบฝึกหัด (quest.html)
- หน้าจอสมรภูมิโค้ดเต็มจอ (Split Screen 2 ฝั่ง) ไม่มีแบบฟอร์มลงทะเบียนมาปน:
  - **แถบ Header ด้านบน**: แสดงชื่อนักเรียน, ชั้น, เลขที่, แถบพลัง XP (0-100 XP), ฉายา, ปุ่มสรุปสูตรไวยากรณ์ 📖, โหมดครูผู้สอน 🔑, เปิด/ปิดเสียง 🔊, เปิด/ปิด CRT 📺, และปุ่มไปหน้าสรุปผล 🏆
  - **แถบเปลี่ยนข้อ (1-10)**: แสดงสถานะข้อที่ผ่านแล้ว (✔) และข้อปัจจุบัน (★)
  - **ฝั่งซ้าย (Quest Card)**: ชื่อโจทย์, ระดับความยาก, คะแนน XP, เนื้อเรื่องเกม RPG, รายละเอียดภารกิจ, **Checklist ตรวจเงื่อนไขแบบเรียลไทม์**, ตัวอย่างผลลัพธ์, และกล่องคำแนะนำ (Hints)
  - **ฝั่งขวา (Code Playground)**:
    - Code Editor (CodeMirror) มีเลขบรรทัด, ไฮไลต์สี Python, ปุ่ม Tab 4 ช่อง, ปรับขนาดฟอนต์ได้ (A+ / A-), ปุ่มรีเซ็ตโค้ด 🔄
    - ปุ่ม **▶ รันโค้ด (Run Code)** และ **🚀 ส่งคำตอบ (Submit Answer)** (คีย์ลัด `Ctrl + Enter`)
    - Terminal สีดำเรโทร แสดงผลลัพธ์การรันจริงแบบเรียลไทม์
    - Validation Banner แจ้งเตือนผลการตรวจ (สีเขียวนีออนพร้อมพลุฉลอง Confetti 🎉 เมื่อผ่าน)
- เมื่อทำครบ 10 ข้อ หรือกดปุ่ม "สรุปผล" จะเปลี่ยนหน้าไปยัง `summary.html`

### 3. หน้าสรุปผลและตารางอันดับ (summary.html)
- หน้าจอสรุปผลคะแนนรวมและเกียรติบัตร:
  - สรุปคะแนนรวมเต็ม 100 XP พร้อมประทับตราฉายาเรโทร (Achievement Stamp: เช่น `👑 Python Grandmaster`)
  - **ตารางจัดอันดับชั้นเรียน (Classroom Leaderboard)**: แสดงอันดับของนักเรียนเปรียบเทียบกับเพื่อนร่วมชั้นแบบไดนามิกพร้อมเหรียญทอง/เงิน/ทองแดง 🥇🥈🥉
  - **ตารางผลการประเมินแยกตามรายข้อ (10 ภารกิจ)**: สรุปคะแนนและเกณฑ์การประเมิน
  - **ปุ่มพิมพ์ใบรายงานผล (Print Report สำหรับส่งครู)**: จัดหน้ากระดาษขนาด **A4** พร้อมหัวกระดาษโรงเรียน ข้อมูลนักเรียน ตารางคะแนน และช่องลงชื่อครูผู้สอน
  - **ปุ่มส่งออกคะแนน (Export CSV)**: บันทึกคะแนนเป็นไฟล์ Excel สำหรับครูนำไปตัดเกรด
  - ปุ่มกลับไปแก้ไขโค้ดในแบบฝึกหัด (`quest.html`)
  - ปุ่มเริ่มต้นใหม่ / เปลี่ยนผู้ใช้งาน (`index.html`)

## 🎯 โจทย์ทดสอบ 10 ภารกิจ (อิงตามหลักสูตร ม.3)

| ข้อ | สาระการเรียนรู้ / หัวข้อ | ระดับ | คะแนน | รายละเอียดภารกิจ |
|:---:|:---|:---:|:---:|:---|
| 1 | `[print()]` | ง่าย | 10 XP | พิมพ์ข้อความ `"Hello, Python!"` ออกทางหน้าจอ |
| 2 | `[# Comment]` | ง่าย | 10 XP | เขียน Comment บรรทัดแรก `# นินจาไพทอน` แล้วใช้ `print()` พิมพ์ `"พร้อมลุย!"` |
| 3 | `[Math Operations]` | ง่าย | 10 XP | แสดงผลการคำนวณเลข `10 + 20` และ `5 * 4` คนละบรรทัด (ไม่ใส่เครื่องหมายคำพูด) |
| 4 | `[Comma Separator]` | ปานกลาง | 10 XP | ใช้ `print()` แสดงข้อความหลายค่าด้วยเครื่องหมายจุลภาค `"คะแนนสอบของฉันคือ", 95, "คะแนน"` |
| 5 | `[Variables]` | ปานกลาง | 10 XP | สร้างตัวแปร `name = "กอน"` และ `power = 100` แล้วใช้ `print()` พิมพ์ค่าตัวแปรทั้งสอง |
| 6 | `[Variable Addition]` | ปานกลาง | 10 XP | สร้าง `num1 = 15`, `num2 = 5` แล้วบวกกันเก็บใน `total = num1 + num2` แล้วพิมพ์ `total` |
| 7 | `[Badge Generator]` | ท้าทาย | 10 XP | เขียน Comment `# บัตรตัวละคร`, สร้าง `hero = "สายฟ้า"`, `level = 50` แล้วพิมพ์ `"ฮีโร่:", hero, "เลเวล:", level` |
| 8 | `[Movie Ticket Calculator]` | ท้าทาย | 10 XP | สร้าง `ticket = 160`, `qty = 3`, `discount = 50` คำนวณ `total = (ticket * qty) - discount` แล้วพิมพ์ `total` (ได้ 430) |
| 9 | `[Fix Syntax Error]` | ท้าทาย | 10 XP | แก้ไขโค้ดที่ผิด: `Print("คะแนนของคุณคือ" score)` (กำหนด `score = 100`) ให้ถูกต้อง |
| 10 | `[Fix Semantic Error]` | ท้าทาย | 10 XP | แก้ไขโค้ดหาค่าเฉลี่ยราคาที่ใส่วงเล็บผิด: `price1 = 80`, `price2 = 20` คำนวณ `avg_price = (price1 + price2) / 2` ให้ได้ผลลัพธ์ 50.0 |
