📖 สมุดสรุปสูตรไวยากรณ์ Python เบื้องต้น (ม.3)

1. คำสั่ง print() แสดงผลข้อความและตัวเลข 
print("ข้อความ")           # แสดงข้อความ
print(10 + 20)            # แสดงผลการคำนวณ 30
print("คะแนน:", 100)       # คั่นด้วยจุลภาค (,) มีเว้นวรรคอัตโนมัติ
2. การเขียน Comment บันทึกความคิด (#) 
# คอมเมนต์ขึ้นต้นด้วยเครื่องหมาย # คอมพิวเตอร์จะไม่นำมารัน
3. ตัวดำเนินการทางคณิตศาสตร์และลำดับความสำคัญ (PEMDAS) 
+ (บวก)  - (ลบ)  * (คูณ)  / (หาร)
ลำดับ: คูณและหารทำก่อนบวกและลบเสมอ!
ถ้าต้องการให้บวกก่อน ต้องใส่วงเล็บ: (price1 + price2) / 2
4. การสร้างตัวแปร (Variables) 
name = "กอน"       # ข้อความ (str) ต้องใส่เครื่องหมายคำพูด
score = 100        # ตัวเลข (int) ไม่ต้องใส่เครื่องหมายคำพูด
total = num1 + num2 # ตัวแปรสามารถนำมาคำนวณกันได้
